# ICカード CSV → マネフォME 自動入力 要件定義書

ICカードの利用履歴をマネフォMEに自動入力するプログラム。

## 入力データの想定：以下の項目からなるCSVファイル

利用日、利用内容（例：「バス」、「運賃支払い（さっぽろ→すすきの）」、「入場時オートチャージ」）、利用金額、大分類（例：支出の場合、交通費など。収入の場合、収入）、小分類（例：支出の場合、電車、バスなど。収入の場合、その他入金など）、マネフォ登録日（初期値null、登録時に記載）
例：2026/06/05, バス, 330, 交通費, バス,

## 動作の想定

- `anapay2mf_icloud-mail.py`と比べ、家計簿タブにある家計簿入力モーダルを利用して入力する点が異なるので注意

1. マネフォMEにアクセス、ログイン（既存プログラムを参考に）
2. 「家計簿」タブに移動（/cf）
3. 「手入力」ボタンを押す
4. 「家計簿入力」というモーダルが現れる。支出の場合は支出タブを押し、収入の場合は収入タブを押して、画面を切り替える。内容を入力する。保存するボタンを押し、最大10秒まつ
5. 入力を保存しました。とでる。次の明細があれば、「続けて入力する」ボタンを押す（入力するものがなければ、「閉じる」ボタンを押し、7. に移動）
6. 4. に戻ってくり返す
7. 終了

## マネフォ入力時のデータの想定

### 支出の場合

日付：ICカードの利用日と同じ
支出元：「SUGOCA」
支出金額：ICカードの利用金額
大分類：ICカードの大分類
小分類：ICカードの小分類
項目：ICカードの利用内容

### 収入の場合

日付：ICカードの利用日と同じ
入金先：「SUGOCA」
収入金額：ICカードの利用金額
大分類：ICカードの大分類
小分類：ICカードの小分類
項目：ICカードの利用内容

## その他

- 指定された大分類、小分類が存在しない場合は無視し、指定しない
- csvはこちらがパスを指定する
- 入力件数は、1回の実行あたり最大100件
