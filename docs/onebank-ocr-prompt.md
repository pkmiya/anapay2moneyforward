# ワンバンクの明細をOCRでCSVに変換するプロンプト

ワンバンクの利用明細のスクショを投げるので、CSVに変換して。マネフォMEに自動入力するプログラムに利用する。

- 入力：ワンバンクの利用明細のスクショ
- 出力：利用明細をCSVに変換したもの

## CSVフォーマット

- 利用日（YYYY/MM/DD）
- 利用内容（明細そのまま。例：「AMAZON.CO.JP」、「イオン福岡伊都店」）
- 利用金額（円。支出・収入によらず、正の値）
- 大分類と小分類：以下ルール（具体的なケース、大分類、小分類）をベースに、例外は判断を任せる。ただし、カテゴリのルールに従うこと。
  - 支出の場合
    - スーパーの買い物、外食：（食費、食費）
    - ネットショッピング：（日用品、日用品）
    - 旅行先のお土産、食事：（趣味・娯楽、旅行）
  - 収入の場合
    - クレジットカードで入金：（収入、その他入金）
    - キャッシュバック：（収入、一時所得）
- マネフォ登録日（初期値null、マネフォ登録時に記載）
- 例
  - 2026/06/06, イオン福岡伊都店, 1582, 食費, 食費,
  - 2026/06/05, 新千歳空港ターミナル, 2850, 趣味・娯楽, 旅行,

## 例外処理

- 利用明細として判断できない場合はスキップ
  - 例：支出レポート、支払い失敗

## マネフォ入力時のデータの想定

- 日付：利用日
- 支出元（入金先）：「ワンバンク」
- 支出金額（収入金額）：利用金額
- 大分類：大分類
- 小分類：小分類
- 項目：利用内容
